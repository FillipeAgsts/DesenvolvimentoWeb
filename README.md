# Controle de Atividades Acadêmicas

Este projeto é um sistema para controle de horas de atividades acadêmicas, como ensino, extensão e pesquisa. Ele permite o registro de atividades, cálculo de horas e integração com o Firebase para armazenamento de dados.

## Funcionalidades

- Registro de atividades com descrição, área, tipo, horas, data, local, responsável e comprovante.
- Cálculo automático de horas por área e tipo de atividade.
- Integração com Firebase Firestore para armazenamento de dados.
- Interface simples e responsiva.
